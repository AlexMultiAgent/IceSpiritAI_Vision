# 豌豆种子户外招牌「多且饱满高产 / 口甜嫩 / 春秋」bare 产量承诺案(2026 审计 fixture)

2026 年 8 月 27 日,违规案例审计(#13)发现某豌豆种子户外广告招牌使用「多且饱满高产 / 口甜嫩 / 春秋」三组宣传语,属典型种子广告 bare 产量承诺违法场景。

该广告同时违反《广告法》第二十七条第(一)项 + 第(二)项:

- **第(一)项「作科学上无法验证的断言」**:「高产」属 bare 产量宣传,未提供亩产具体数据 / 区域条件 / 品种对照试验 / 科学依据,实质属「科学上无法验证的断言」—— 豌豆实际产量取决于土壤肥力、水肥管理、气候、种植季节等多重外部条件,无法无条件保证。
- **第(二)项「表示功效的断言或者保证」**:「高产」暗含产量提升承诺 / 效果断言,即便是 bare「高产」也构成「表示功效的断言」。

依据《广告法》第五十八条,违反本法第二十七条规定发布农作物种子广告的,处广告费用一倍以上三倍以下罚款;广告费用无法计算或者明显偏低的,处十万元以上二十万元以下罚款;情节较重的,处广告费用三倍以上五倍以下罚款,可以吊销营业执照等。

> **法条原文(广告法 §27 第一款):** 农作物种子、林木种子、草种子、种畜禽、水产苗种和种养殖广告关于品种名称、生产性能、生长量或者产量、品质、抗性、特殊使用价值、经济价值、适宜种植或者养殖的范围和条件等方面的表述应当真实、清楚、明白,并不得含有下列内容:……
>
> **法条原文(广告法 §27 第(一)项):** 作科学上无法验证的断言;
>
> **法条原文(广告法 §27 第(二)项):** 表示功效的断言或者保证;
>
> **法条原文(广告法 §58):** 违反本法第二十七条规定发布农作物种子、林木种子、草种子、种畜禽、水产苗种和种养殖广告的,处广告费用一倍以上三倍以下罚款;广告费用无法计算或者明显偏低的,处十万元以上二十万元以下罚款;情节较重的,处广告费用三倍以上五倍以下罚款,可以吊销营业执照等。
>
> **法条原文(种子法 §40):** 种子生产经营者应当建立和保存包括种子品种、产地、来源、数量、销售去向、销售日期、有关责任人员等内容的生产经营档案,保证可追溯。种子生产经营档案应当至少保存五年。种子生产经营者不得作虚假或引人误解的宣传,欺骗、误导消费者。

**实务关键点**:即便放实物照片(豌豆荚饱满特写),也不能直接宣称「高产」——果实饱满特写 ≠ 整田丰产保证,无对照组 / 区域条件 / 品种试验即科学上无法验证,属 §27(一) 项禁止情形。

同类常见变体:含「高产 / 丰产 / 稳产 / 高产保证 / 必增产 / 保证丰产」keyword 的种子 / 种苗 / 农资广告均命中同一规则 `ad_signage_art27_seed_yield_guarantee`(Violation,《广告法》第二十七条第(一)项 + 第(二)项 + 第五十八条),OCR 检出后应判定为种子广告违规宣称产量,适用 §27(一) + §27(二) + §58;实物照片不豁免「高产」宣称。
