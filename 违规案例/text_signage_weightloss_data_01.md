# 减肥产品电商页「2 个月减重 31 斤 / 腰围缩了 10CM」虚构减重效果案(2026 审计 fixture)

2026 年 8 月 27 日,违规案例审计(#38)发现某体重管理减肥产品在电商平台销售页宣传「2 个月减重 31 斤」「50 天减重 27.1 斤 腰围缩了 10CM」「14 天减重 8 斤」「21 天减重 10.2 斤」,并以「调养脾胃 · 体重管理」包装中医减肥暗示。该减肥产品在电商页虚构具体减重数据 + 期限 + 围度变化效果保证,属《广告法》第二十八条第二款第(四)项禁止的「虚构使用商品或者接受服务的效果」情形;同时落《广告法》第十八条保健食品广告禁制(表示功效、安全性的断言或保证)+ 第十七条非医疗 / 药品 / 医疗器械广告涉及保健功能情形。

依据《广告法》第五十八条,违反本法第十七条规定,在广告中涉及疾病治疗功能,以及使用医疗用语或者易使推销的商品与药品、医疗器械相混淆的用语的,或违反本法第十八条规定发布保健食品广告的,由市场监督管理部门责令停止发布广告,处广告费用一倍以上三倍以下的罚款,广告费用无法计算或者明显偏低的,处十万元以上二十万元以下的罚款;情节严重的,处广告费用三倍以上五倍以下的罚款,广告费用无法计算或者明显偏低的,处二十万元以上一百万元以下的罚款。

> **法条原文(广告法 §17):** 除医疗、药品、医疗器械广告外,禁止其他任何广告涉及疾病治疗功能,并不得使用医疗用语或者易使推销的商品与药品、医疗器械相混淆的用语。
>
> **法条原文(广告法 §18 第(一)项):** 保健食品广告不得含有下列内容:(一)表示功效、安全性的断言或者保证;……
>
> **法条原文(广告法 §28 第二款第(四)项):** 广告有下列情形之一的,为虚假广告:……(四)虚构使用商品或者接受服务的效果的;……
>
> **法条原文(广告法 §58 第二款第(二)、(三)项):** 由市场监督管理部门责令停止发布广告,处广告费用一倍以上三倍以下的罚款,广告费用无法计算或者明显偏低的,处十万元以上二十万元以下的罚款;情节严重的,处广告费用三倍以上五倍以下的罚款,广告费用无法计算或者明显偏低的,处二十万元以上一百万元以下的罚款。

同类常见变体:含「两月减重 / 月减重 / 天减重 / 周减重 / 腰围缩了 / 腰围缩 / 体重管理 / 瘦身计划」keyword 的减肥产品电商页 / 户外招牌 / 销售页均命中同一规则 `ad_signage_signage_weight_loss_data_commitment`(Violation,《广告法》第十七条 + 第十八条 + 第二十八条 + 第五十八条),OCR 检出后应判定为虚构减重效果违规,适用 §17 + §18 + §28 + §58。「X 月瘦 X 斤 / X 天瘦 X 斤 / 腰围瘦 X CM / 体重下降 X 斤 / 减肥 X 斤 / 减脂 X 斤」等同义变体应同样命中;「调养脾胃减肥 / 祛湿减肥 / 经络减肥」等中医减肥暗示可同时触发医疗用语规则。
