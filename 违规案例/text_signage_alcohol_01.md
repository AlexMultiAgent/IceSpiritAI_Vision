# 白酒电商页「闻香 / 入口 / 天然桦树清香」酒类广告场景案(2026 审计 fixture)

2026 年 8 月 27 日,违规案例审计(#18)发现某白酒品牌在电商平台发布的商品详情页中,以「闻香 天然桦树清香」「入口 层次丰富 清爽顺滑」等感官描述宣传其白酒产品。该电商页虽未直接违反《广告法》第二十三条酒类广告 4 项明文禁制情形(未诱导无节制饮酒 / 未出现饮酒动作 / 未表现驾驶活动 / 未明示暗示饮酒有消除紧张焦虑 / 增加体力等功效),但作为「酒类广告场景」,仍受《广告法》第二十三条与《酒类广告管理办法》的全面约束,场景识别为该规则的核心命中点。

依据《广告法》第五十七条,违反本法第二十三条规定发布酒类广告的,由市场监督管理部门责令停止发布广告,对广告主处二十万元以上一百万元以下的罚款,情节严重的,并可以吊销营业执照。

> **法条原文(广告法 §23):** 酒类广告不得含有下列内容:(一)诱导、怂恿饮酒或者宣传无节制饮酒;(二)出现饮酒的动作;(三)表现驾驶车、船、飞机等活动;(四)明示或者暗示饮酒有消除紧张和焦虑、增加体力等功效。
>
> **法条原文(广告法 §57):** 违反本法第二十三条规定发布酒类广告的,由市场监督管理部门责令停止发布广告,对广告主处二十万元以上一百万元以下的罚款,情节严重的,并可以吊销营业执照。

同类常见变体:含「白酒 / 茅台 / 五粮液 / 洋河 / 剑南春 / 泸州老窖 / 汾酒 / 酒类 / 酒精度 / 纯粮 / 闻香 / 清爽顺滑 / 商务宴请 / 陈酿」keyword 的电商页 / 户外招牌 / 销售页均命中同一规则 `ad_signage_signage_alcohol_drink_scenario`(Warning,《广告法》第二十三条 + 第五十七条),OCR 检出后应判定为酒类广告场景,适用 §23 + §57。如同时含 §23 第(一) ~ (四)项明文禁制情形(如「多喝点没事」/「喝完开车不危险」/「酒后降压」),应升级为更严重情形处理。
