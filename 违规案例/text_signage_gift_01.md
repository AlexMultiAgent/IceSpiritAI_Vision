# 食品电商礼盒「送领导 / 送客户 / 节日回送」公务 / 商务送礼诱导案(2026 审计 fixture)

2026 年 8 月 27 日,违规案例审计(#20)发现某电商平台「黑尊牛 安格斯牛肉礼盒」销售页,宣传「春节礼品 节日回送 送领导 送客户」,以「清真」为卖点之一诱导消费者用于公务 / 商务送礼场景。该营销话术将普通食品礼盒与「送领导 / 答谢客户 / 单位团购 / 机关送礼」绑定,属《广告法》第九条第(七)项禁止的「妨碍社会公共秩序或者违背社会良好风尚」情形 — 公务人员收受食品礼品可能违反中央八项规定及廉洁从政要求,广告主以「送领导」为卖点已构成价值观导向错误;同页「中国安格斯肉牛之乡 - 孙吴」属地理标志无依据宣称,违反 §28 商品产地信息与实际情况不符。

依据《广告法》第五十七条,发布有本法第九条第一款规定的禁止情形广告的,由市场监督管理部门责令改正,对广告主处二十万元以上一百万元以下的罚款。

> **法条原文(广告法 §9 第(七)项):** 广告不得有下列情形:……(七)妨碍社会公共秩序或者违背社会良好风尚;……
>
> **法条原文(广告法 §28 第二款第(二)项):** 广告有下列情形之一的,为虚假广告:……(二)商品的性能、功能、产地、用途、质量、规格、成分、价格、生产者、有效期限、销售状况、曾获荣誉等信息,或者服务的内容、提供者、形式、质量、价格、销售状况、曾获荣誉等信息,以及与商品或者服务有关的允诺等信息与实际情况不符,对购买行为有实质性影响的;……
>
> **法条原文(广告法 §57):** 有下列行为之一的,由市场监督管理部门责令停止发布广告,对广告主处二十万元以上一百万元以下的罚款,情节严重的,并可以吊销营业执照……(一)发布有本法第九条、第十条规定的禁止情形的广告的;……

同类常见变体:含「送领导 / 送上级 / 送老板 / 送客户 / 节日礼品 / 商务礼 / 送礼首选 / 公务送礼 / 单位团购 / 机关送礼 / 答谢客户 / 员工福利 / 礼盒装」keyword 的电商页 / 户外招牌 / 销售页均命中同一规则 `ad_signage_signage_gift_to_leader`(Warning),OCR 检出后应判定为违背社会良好风尚(公务 / 商务送礼诱导),适用 §9 第(七)项 + §28 + §57。若商品同时出现「清真认证」等民族 / 宗教标签,可配合 §9(七)进一步强化违法情节。
