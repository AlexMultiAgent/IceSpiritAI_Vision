# 公考培训「某省直机关在职中层领导」国家机关工作人员身份背书案(2026 审计 fixture)

2026 年 8 月 27 日,违规案例审计(#32)发现某公考培训机构师资宣传页,讲师「宋尚案老师」简介含「某省直机关在职中层领导」「多年黑龙江省考、事业单位考试面试官」字样。该广告将国家机关工作人员在职身份与公考培训机构师资绑定,属《广告法》第九条第(二)项禁止的「使用或者变相使用国家机关、国家机关工作人员的名义或者形象」情形;同时「多年黑龙江省考、事业单位考试面试官」属《广告法》第二十四条第(三)项禁止的「明示或者暗示有相关考试机构或者其工作人员、考试命题人员参与教育、培训」情形;同讲师在职兼职授课亦违反《公务员法》第五十九条第(十六)项「公务员不得违反有关规定从事或者参与营利性活动」。

依据《广告法》第五十七条,发布有本法第九条规定禁止情形广告的,由市场监督管理部门责令改正,对广告主处二十万元以上一百万元以下的罚款,情节严重的,并可以吊销营业执照、吊销广告发布登记证件;违反第二十四条规定发布教育、培训广告的,依据第五十八条第二款第(六)项处广告费用一倍以上三倍以下的罚款。

> **法条原文(广告法 §9 第(二)项):** 广告不得有下列情形:……(二)使用或者变相使用国家机关、国家机关工作人员的名义或者形象;……
>
> **法条原文(广告法 §24 第(三)项):** 教育、培训广告不得含有下列内容:……(三)利用科研单位、学术机构、教育机构、行业协会、专业人士、受益者的名义或者形象作推荐、证明。
>
> **法条原文(广告法 §57 第(一)项):** 有下列行为之一的,由市场监督管理部门责令停止发布广告,对广告主处二十万元以上一百万元以下的罚款,情节严重的,并可以吊销营业执照,吊销广告发布登记证件:……(一)发布有本法第九条、第十条规定的禁止情形的广告的;……
>
> **法条原文(公务员法 §59 第(十六)项):** 公务员应当遵纪守法,不得有下列行为:……(十六)违反有关规定从事或者参与营利性活动,在企业或者其他营利性组织中兼任职务;……

同类常见变体:含「某省直机关在职 / 在职中层领导 / 在职机关人员 / 在职公务员代言 / 公务员兼职培训 / 公职人员推荐 / 机关事业单位在职人员推荐 / 在职公考」keyword 的公考培训 / 事业单位考试培训 / 教师资格证培训 / 司法考试培训等教育广告均命中同一规则 `ad_signage_edu_art24_public_servant_endorsement`(Violation,《广告法》第九条第(二)项 + 第二十四条第(三)项 + 第五十七条 + 第五十八条),OCR 检出后应判定为教育培训机构利用国家机关工作人员 / 考试机构人员身份背书违规,适用 §9(二) + §24(三) + §57 + §58 + 《公务员法》§59(十六)。
