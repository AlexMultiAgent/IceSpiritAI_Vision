# 运动营养食品电商页「清肺排毒 / 提升肺功能 / 2 瓶拥有 1 健康好肺」肺部保健宣称案(2026 审计 fixture)

2026 年 8 月 27 日,违规案例审计(#41)发现某「肺肽片」保健食品在电商平台销售页宣传「清肺排毒」「提升肺功能」「2 瓶拥有 1 健康好肺」。该产品注册类别为运动营养食品(耐力类),与「肺功能」宣称的产品分类不匹配 — 保健食品的「保健功能」分类有 27 项明确目录(国家市场监督管理总局《保健食品原料目录与保健功能目录管理办法》),「清肺 / 提升肺功能」不在任何保健功能目录内,实质属普通食品宣称疾病预防 / 治疗功能。

该广告违反《广告法》第十八条第(一)项「保健食品广告不得含有下列内容:(一)表示功效、安全性的断言或者保证」— 「2 瓶拥有 1 健康好肺」属明确效果断言与保证;同时违反第(二)项「涉及疾病预防、治疗功能」— 「清肺排毒 / 提升肺功能」均涉及肺部保健(肺部炎症 / 肺功能下降属典型疾病症状);亦落《广告法》第十七条非医疗 / 药品 / 医疗器械广告涉及疾病治疗功能情形。

依据《广告法》第五十八条,违反本法第十七条规定或第十八条规定发布保健食品广告的,由市场监督管理部门责令停止发布广告,处广告费用一倍以上三倍以下的罚款,广告费用无法计算或者明显偏低的,处十万元以上二十万元以下的罚款;情节严重的,处广告费用三倍以上五倍以下的罚款,广告费用无法计算或者明显偏低的,处二十万元以上一百万元以下的罚款。

> **法条原文(广告法 §17):** 除医疗、药品、医疗器械广告外,禁止其他任何广告涉及疾病治疗功能,并不得使用医疗用语或者易使推销的商品与药品、医疗器械相混淆的用语。
>
> **法条原文(广告法 §18):** 保健食品广告不得含有下列内容:(一)表示功效、安全性的断言或者保证;(二)涉及疾病预防、治疗功能;(三)声称或者暗示广告商品为保障健康所必需;(四)与药品、其他保健食品进行比较;(五)利用广告代言人作推荐、证明;(六)法律、行政法规规定禁止的其他内容。
>
> **法条原文(广告法 §58):** 有下列行为之一的,由市场监督管理部门责令停止发布广告,责令广告主在相应范围内消除影响,处广告费用一倍以上三倍以下的罚款,广告费用无法计算或者明显偏低的,处十万元以上二十万元以下的罚款;情节严重的,处广告费用三倍以上五倍以下的罚款,广告费用无法计算或者明显偏低的,处二十万元以上一百万元以下的罚款:……(二)违反本法第十七条规定,在广告中涉及疾病治疗功能,以及使用医疗用语或者易使推销的商品与药品、医疗器械相混淆的用语的;(三)违反本法第十八条规定发布保健食品广告的;……

同类常见变体:含「清肺 / 清肺排毒 / 提升肺功能 / 养肺 / 润肺 / 清肺解毒 / 肺功能」keyword 的食品 / 保健食品 / 普通食品电商页 / 户外招牌均命中同一规则 `ad_signage_signage_food_lung_health_claim`(Violation,《广告法》第十七条 + 第十八条 + 第五十八条),OCR 检出后应判定为食品 / 保健食品违规宣称肺部保健功能,适用 §17 + §18 + §58。「清肺茶 / 润肺茶 / 养肺汤 / 护肺食品 / 烟民清肺 / 排出肺毒 / 修复肺损伤」等同义变体应同样命中。
