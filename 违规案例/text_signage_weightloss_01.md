# 普通食品电商页「减脂 / 减肥 / 通便 / 美白」保健功能宣称案(2026 审计 fixture)

2026 年 8 月 27 日,违规案例审计(#28 + #54 合并 1 规则)发现两例普通食品在电商平台违规宣称保健功能 / 减肥功能:

- **#28 「千禧小柿子 减脂 美白 补水 抗氧化 高 VC」**:某电商平台上架的「千禧小柿子」水果商品页,宣传「减脂」「美白」「补水」「抗氧化」「高 VC」等保健功能,该产品为普通水果(非保健食品,无蓝帽子标识),属《广告法》第十七条禁止情形 — 非医疗 / 药品 / 医疗器械广告涉及疾病治疗或保健功能,且若以「减脂」为减肥功能宣称亦落 §18 保健食品广告禁制范围(普通食品无保健食品资质)。
- **#54 「京东京造菊粉代餐 减肥 便秘通便」**:京东自有品牌「京东京造 菊粉代餐」电商商品页,宣传「减肥」「便秘通便」,该产品为普通代餐食品(非保健食品,无蓝帽子标识),属《广告法》第十七条 + 第十八条禁止情形。

依据《广告法》第五十八条第二款第(三)项,违反第十八条规定发布保健食品广告的,由市场监督管理部门责令停止发布广告,处广告费用一倍以上三倍以下的罚款,广告费用无法计算或者明显偏低的,处十万元以上二十万元以下的罚款;情节严重的,处广告费用三倍以上五倍以下的罚款,广告费用无法计算或者明显偏低的,处二十万元以上一百万元以下的罚款。

> **法条原文(广告法 §17):** 除医疗、药品、医疗器械广告外,禁止其他任何广告涉及疾病治疗功能,并不得使用医疗用语或者易使推销的商品与药品、医疗器械相混淆的用语。
>
> **法条原文(广告法 §18):** 保健食品广告不得含有下列内容:(一)表示功效、安全性的断言或者保证;(二)涉及疾病预防、治疗功能;(三)声称或者暗示广告商品为保障健康所必需;(四)与药品、其他保健食品进行比较;(五)利用广告代言人作推荐、证明;(六)法律、行政法规规定禁止的其他内容。
>
> **法条原文(广告法 §58):** 有下列行为之一的,由市场监督管理部门责令停止发布广告,责令广告主在相应范围内消除影响,处广告费用一倍以上三倍以下的罚款……(二)违反本法第十七条规定,在广告中涉及疾病治疗功能,以及使用医疗用语或者易使推销的商品与药品、医疗器械相混淆的用语的;(三)违反本法第十八条规定发布保健食品广告的;……

同类常见变体:含「代餐减肥 / 减肥代餐 / 菊粉代餐 / 代餐 / 减肥 / 瘦身 / 减脂 / 通便 / 便秘通便」keyword 的普通食品电商页 / 户外招牌 / 销售页均命中同一规则 `ad_signage_signage_weight_loss_food_claim`(Violation,《广告法》第十七条 + 第十八条 + 第五十八条),OCR 检出后应判定为普通食品违规宣称减肥 / 保健功能,适用 §17 + §18 + §58。「减肥水果 / 减肥蔬菜 / 减肥茶 / 减肥咖啡 / 减肥巧克力 / 刮油食品」等同义变体应同样命中。
