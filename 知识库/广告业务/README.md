# 广告业务 法规知识库索引

本目录收录广告业务现行有效法律法规的权威全文,作为拍照识别 / OCR 后判别的法规依据。每份 markdown 含:
- 发文字号、发文机关、通过日期、施行日期、当前有效性
- 官方 URL(优先 flk.npc.gov.cn / samr.gov.cn / openstd.samr.gov.cn / gov.cn)
- 原文
- 适用判别要点(可由 OCR 后关键词触发的判别条目)

## 同步说明

本目录与代码层 `app/src/main/assets/rules/<domain>_rules.json` 是 1:N 关系 — 一份法规可能对应多条规则。每条规则的 `regulation` 字段就是 markdown 文件内的具体条文引用, `lawText` 字段摘抄自对应 markdown 段, `rule.id` 用 `<domain>_<article>_<short>` 命名(例 `ad_signage_art9_abs`, `food_gb7718_nozero_add`)。每次增加规则都可回溯到知识库文件。
本目录为一次性人工梳理,后续 PM 按需同步。
