## 原文

**第一条** 为了规范化妆品生产经营活动,加强化妆品监督管理,保证化妆品质量安全,保障消费者健康,制定本条例。

**第二条** 在中华人民共和国境内从事化妆品生产经营活动及其监督管理,应当遵守本条例。

**第三条** 本条例所称化妆品,是指以涂擦、喷洒或者其他类似方法,施用于皮肤、毛发、指甲、口唇等人体表面,以清洁、保护、美化、修饰为目的的日用化学工业产品。

**第十七条** 化妆品分为特殊化妆品和普通化妆品。国家对特殊化妆品实行注册管理,对普通化妆品实行备案管理。

特殊化妆品用于染发、烫发、祛斑美白、防晒、防脱发的化妆品以及宣称新功效的化妆品。特殊化妆品以外的化妆品为普通化妆品。

国务院药品监督管理部门根据化妆品的功效宣称、作用部位、产品剂型等,制定、公布化妆品分类规则和分类目录。

**第十八条** 特殊化妆品经国务院药品监督管理部门注册后方可生产、进口。国产普通化妆品应当在上市销售前向备案人所在地省、自治区、直辖市人民政府药品监督管理部门备案。进口普通化妆品应当在进口前向国务院药品监督管理部门备案。

**第十九条** 化妆品的注册人、备案人对化妆品的质量安全和功效宣称负责,受托生产企业对受托生产行为负责。

注册人、备案人、受托生产企业应当依照法律、法规、强制性国家标准和技术规范的要求,从事化妆品生产经营活动,加强生产经营管理,保证化妆品质量安全。

**第二十条** 化妆品的功效宣称应当有充分的科学依据,依据可以是相关的研究数据、文献资料或者消费者评价等。化妆品注册人、备案人对化妆品的功效宣称承担相应的法律责任。

**第二十一条** 化妆品的注册证书、备案信息、注册和备案的产品配方、生产工艺、标签、原料和安全性评价资料等,应当妥善保存,供社会公众查询。国务院药品监督管理部门应当向社会公开注册和备案相关信息。

**第二十二条** 化妆品的最小销售单元应当有标签。标签应当符合相关法律、行政法规、强制性国家标准和技术规范的规定。标签内容应当真实、完整、准确,不得含有虚假或者引人误解的内容,不得欺骗、误导消费者。

**第二十三条** 化妆品标签应当标注下列内容:

(一) 产品名称、特殊化妆品注册证编号或者普通化妆品备案编号;

(二) 注册人、备案人、受托生产企业的名称、地址;

(三) 化妆品生产许可证编号;

(四) 产品执行的标准编号;

(五) 全成分;

(六) 净含量;

(七) 使用期限、使用方法、必要的安全警示;

(八) 法律、行政法规和强制性国家标准规定应当标注的其他内容。

**第二十四条** 特殊化妆品注册证编号应当清晰、易于识别。注册证编号的格式由国务院药品监督管理部门规定。

**第二十五条** 化妆品的广告宣传不得含有虚假或者引人误解的内容,不得欺骗、误导消费者。

化妆品广告不得明示或者暗示产品具有医疗作用,不得含有虚假或者引人误解的内容。

**第二十六条** 化妆品经营者应当建立进货查验记录和产品销售记录制度,确保产品来源可追溯、去向可查证。

**第二十七条** 电子商务平台经营者应当对平台内化妆品经营者进行实名登记,承担平台内化妆品经营者的管理责任。

**第二十八条** 国务院药品监督管理部门制定化妆品生产经营质量管理规范,化妆品生产经营者应当按照质量管理规范组织生产经营活动。

**第二十九条** 化妆品注册和备案的监督管理由国务院药品监督管理部门负责;生产经营环节的监督管理由县级以上地方人民政府负责药品监督管理的部门负责。

**第三十条** 化妆品监督管理过程中知悉的商业秘密、个人隐私应当依法予以保密。

**第三十一条** 国务院药品监督管理部门可以对化妆品生产经营者开展飞行检查,被检查单位应当配合,不得拒绝、阻碍。

**[第三十二条至第五十条]**: 生产经营许可、监督管理、风险监测与评估、应急处置、监督管理措施、法律责任等内容,详见国务院令第 727 号原文。

**第五十一条** 违反本条例规定,构成犯罪的,依法追究刑事责任。

**第五十二条** 本条例自 2021 年 1 月 1 日起施行。《化妆品卫生监督条例》同时废止。

## 适用判别要点

化妆品广告 / 标签的 OCR 后判别关键词,可触发规则库命中:

- **明示或暗示医疗作用** → §23 + §25 + §26 第二款 → 关键词触发"治疗""治愈""疗效""祛斑""祛痘""消炎""抑菌""修复细胞""抗炎""消肿""缓解""治愈""祛疤""治疗皮炎""祛红血丝""修复肌肤屏障""抗敏"等。
- **虚假或引人误解的内容** → §23 + §25 → 关键词触发"纯天然""无添加""零刺激""100% 安全""绝对安全""彻底告别""一次见效""立竿见影""包治"等。
- **功效宣称无科学依据** → §20 → 关键词触发"研究表明""最新科技""专利配方""国家级科研"等模糊来源。
- **必载特殊化妆品注册证编号缺失**(特殊化妆品)→ §23 第(一)项 + §18 → 关键词触发"国妆特字"缺失。
- **必载普通化妆品备案编号缺失**(普通化妆品)→ §23 第(一)项 + §18 → 关键词触发"国妆网备字"缺失。
- **必载注册人/备案人/受托生产企业名称地址缺失** → §23 第(二)项 → 关键词触发"注册人""备案人""受托生产""地址"等缺失提示。
- **必载生产许可证编号缺失** → §23 第(三)项 → 关键词触发"XK16-108""化妆品生产许可证"等缺失。
- **必载全成分缺失** → §23 第(五)项 → 关键词触发"成分"缺失 / "Ingredients" 缺失。
- **必载净含量缺失** → §23 第(六)项 → 关键词触发"净含量""净重""NET WT""Net Weight"缺失。
- **必载使用期限 / 使用方法 / 安全警示缺失** → §23 第(七)项 → 关键词触发"限期使用日期""生产批号和限期使用日期""使用方法""安全警示""请置于儿童接触不到的地方""避免入眼"等缺失。
- **欺骗误导消费者** → §22 + §25 → 关键词触发"欺骗""误导""引人误解"。
- **经营者进货查验记录缺失** → §26 → 涉及批发零售环节商品源头证据,非 OCR 触发,提示仅供溯源。
