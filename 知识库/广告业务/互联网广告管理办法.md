# 《互联网广告管理办法》

## 原文

**第一条** 为了规范互联网广告活动,保护消费者的合法权益,维护公平竞争的市场经济秩序,根据《中华人民共和国广告法》《中华人民共和国电子商务法》等法律,制定本办法。

**第二条** 在中华人民共和国境内,利用网站、网页、互联网应用程序等互联网媒介,直接或者间接地推销商品或者服务的商业广告活动,适用本办法。

**第三条** 本办法所称互联网广告,是指通过互联网媒介,以文字、图片、音频、视频或者其他形式,直接或者间接地推销商品或者服务的商业广告。

**第四条** 利用互联网广告推销商品或者服务,应当遵守法律、法规,诚实信用,公平竞争。

**第五条** 互联网广告应当真实、合法,以健康的表现形式表达广告内容,符合社会主义精神文明建设和弘扬中华民族优秀传统文化的要求。

**第六条** 互联网广告应当具有可识别性,应当显著标明"广告",使消费者能够辨明其为广告。

通过互联网媒介,以竞价排名、新闻报道、经验分享、测评软文、植入式广告等形式推销商品或者服务的,应当在显著位置标明"广告"。

**第七条** 下列商品或者服务的广告,未经审查不得发布:

(一) 医疗、药品、医疗器械、农药、兽药、保健食品、特殊医学用途配方食品、婴幼儿配方乳粉和其他依法需要进行广告审查的商品或者服务。

未经审查,不得发布前款规定的商品或者服务的广告。互联网广告发布前,广告主应当向广告审查机关申请广告审查,获得广告审查批准文件后,方可发布互联网广告。

**第八条** 禁止利用互联网发布处方药和烟草(含电子烟)广告。

禁止利用互联网发布保健食品、特殊医学用途配方食品、婴幼儿配方乳粉以外的食品的广告,以及法律、行政法规规定禁止生产、销售的商品或者提供的服务的广告。

**第九条** 互联网广告不得含有虚假或者引人误解的内容,不得欺骗、误导消费者。

以介绍健康、养生知识等形式,变相发布医疗、药品、医疗器械、保健食品、特殊医学用途配方食品广告的,属于违反本办法第七条规定的广告。

**第十条** 利用互联网发布医疗、药品、医疗器械、农药、兽药、保健食品、特殊医学用途配方食品的广告,应当显著标明广告审查批准文号;未经审查,不得发布。

互联网广告发布者、广告经营者应当对广告内容的真实性、合法性负责,应当查验广告审查批准文件,核对广告内容,不得发布内容与审查批准文件不符的广告。

**第十一条** 互联网广告发布者、广告经营者应当建立、健全互联网广告业务的承接登记、审核、档案管理制度,应当配备熟悉广告法规的广告审核人员。

**第十二条** 互联网广告发布者、广告经营者应当按照国家有关规定,建立、健全广告监测制度,及时发现和制止违法广告。

**第十三条** 互联网广告发布者应当采取必要措施,防范和制止在其网站、网页、互联网应用程序等互联网媒介上发布的违法广告。

**第十四条** 互联网广告发布者、广告经营者、广告主不得通过任何方式,故意曲解、误导、欺骗、胁迫消费者。

**第十五条** 互联网广告发布者利用互联网发布广告的,应当显著标明"广告",并确保消费者能够一键关闭。

以弹出等形式发布的互联网广告,应当显著标明关闭标志,确保一键关闭。

**第十六条** 互联网平台经营者应当对利用其平台发布的广告内容进行监测,发现违法广告的,应当依法采取处置措施,保存有关记录,并向广告发布者所在地县级以上市场监督管理部门报告。

**第十七条** 利用互联网发布广告的,广告主应当对广告内容的真实性负责。

广告主自行发布广告的,应当具备相应的资质,并对其发布的广告内容负责。

**第十八条** 通过互联网媒介推销商品或者服务的广告主,应当依法履行下列义务:

(一) 查验与其合作的广告经营者、广告发布者的经营资质;

(二) 委托具有相应资质的广告经营者、广告发布者发布广告;

(三) 对广告内容的真实性负责;

(四) 建立广告业务承接登记、审核、档案管理制度;

(五) 法律、行政法规规定的其他义务。

**第十九条** 互联网广告经营者、广告发布者应当依法查验广告主的主体身份信息,登记广告主的真实身份、地址和有效联系方式,建立广告经营者、广告发布者、广告主档案。

**第二十条** 利用互联网发布广告的,广告发布者应当按照广告管理制度的要求,核对广告内容;广告内容违反法律、行政法规的,不得发布。

**第二十一条** 以竞价排名等形式出现的互联网广告,应当显著标明"广告",并与自然搜索结果明显区分。

**第二十二条** 互联网广告发布者利用算法推荐等方式发布互联网广告的,应当将其算法推荐服务相关规则、广告投放规则、广告主及其发布的广告内容等信息,以适当方式告知消费者。

**第二十三条** 利用互联网发布广告的,广告经营者、广告发布者、广告主不得利用互联网信息服务提供者提供的技术手段,妨碍市场监管部门对违法广告的监测和监管。

**[第二十四条至第三十一条]**: 监督检查、行政强制、法律责任等内容,详见国家市场监督管理总局令第 72 号原文。

**第三十二条** 本办法自 2023 年 5 月 1 日起施行。2016 年 7 月 4 日国家工商行政管理总局令第 87 号公布的《互联网广告管理暂行办法》同时废止。

## 适用判别要点

互联网广告的 OCR 后判别关键词,可触发规则库命中:

- **未显著标明"广告"**(可识别性义务) → §6 + §15 + §21 → 关键词触发软文 / 测评 / 分享类描述:"亲测""种草""分享""达人推荐""种草日记""好物推荐""排行榜""测评""热门推荐"等,若缺乏"广告"标识或"AD""advertisement"显著字样即触发。
- **竞价排名未显著标明"广告"** → §21 → 关键词触发"百度推广""搜狗推广""广告位""竞价排名""P4P""付费搜索"等若未标明"广告"即触发。
- **未显著标明关闭标志 / 一键关闭缺失** → §15 第二款 → 关键词触发"打开 App 弹出"且缺乏"关闭""跳过""×""Skip""关闭按钮"等关闭字样即触发。
- **变相发布医疗药品广告**(以健康养生知识形式) → §9 第二款 → 关键词触发"健康讲座""养生秘笈""老中医""专家解读""养生堂""健康之路""养生秘方"等形式包装医疗/药品/医疗器械/保健食品/特殊医学用途配方食品内容。
- **未审查发布处方药 / 烟草 / 电子烟** → §8 → 关键词触发"电子烟""戒烟灵""处方药""Rx"等在互联网广告场景(配合"购买链接""立即购买""扫码加购"等购买链路提示)。
- **保健食品/特医食品/婴幼儿配方乳粉以外的食品广告** → §8 第二款 → 注意此条禁止非特殊膳食用食品的食品互联网广告(此条与一般认知相反,实务中存在一定争议,详见 SAMR 解读)。
- **未经事前审查发布医疗/药品/医疗器械/农药/兽药/保健食品/特医食品/婴幼儿配方乳粉广告** → §7 + §10 → 关键词触发相应品类(配合"广告审查批准文号""审查批件""XK""药广审"等是否标明)。
- **广告内容与审查批准文件不符** → §10 第三款 → 配合审查批件号缺失 / 不对应。
- **未建立承接登记 / 审核 / 档案管理制度** → §11 → 非 OCR 触发,提示仅供溯源。
- **未告知算法推荐规则** → §22 → 涉及 App 端"算法推荐""智能推荐"等语,需结合用户交互层判断。
