## §数字修正 vs 600a23c 注释

600a23c 注释目前是这样写的:

> 但 AdSignageAuditSixtySixImageE2ETest 整体覆盖率掉:FULL 44 → 26 / PARTIAL 18 → 33 / MISS 4 → 5,
> FULL+PARTIAL 62/66=93.9% → 59/65=90.8%(−3.1 pp);总 score 172/198 → 151/198(−10.6 pp)
> 退化 33 张 vs 改善 12 张,噪声类(art28b_fake_data / art11_data_citation / art9_abs_pct)
> 在长图 / 副标题文本中被拉成"已覆盖"假象,但与 ground-truth rule 集合的交集变小,
> 反把 FULL 拉到 PARTIAL、把 PARTIAL 拉到 MISS

**实际数字(以 current main 重跑为准)**:

- config A baseline: 27 FULL / 32 PARTIAL / 6 MISS / 1 NO_GT = 59/65 = **90.8% FULL+PARTIAL**(不是 93.9%)
- config B Phase 2: 26 FULL / 33 PARTIAL / 5 MISS / 1 NO_GT = 59/65 = 90.8% FULL+PARTIAL

**结论修正**:

- config A 与 config B 在 current main 上**整体 FULL+PARTIAL 占比相同**(90.8%),只分布略不同
- 600a23c 注释中"Phase 2 净负 −3.1pp"论断**不复现**:在 current main 上,config B 既不比 config A 差,也不显著更好
- 但 config B 性能上比 config A **慢 43%**(warm_avg 3,833ms vs 2,198ms),所以保留 config A 是对的
- "44 FULL baseline" 数字可能来自 fixture rename / 规则 keyword 扩词之前的快照,不能锚定为"原来 baseline"

**后续不再 bump 600a23c**(commit 已在双远端);后续在 [followup-2026-08-29.md] 跟踪 6 MISS 的修复优先级。
