# 应用内冰灵素材（透明抠图 PNG）

> 首页 Idle 预览区的吉祥物占位图如何生成，以及空态装饰图的尺寸约定。
> 启动图标另见 [`launcher-icon-generation.md`](launcher-icon-generation.md)。

## 1. 当前用途

| 位置 | 资源 | 显示尺寸 |
| --- | --- | --- |
| `ImagePreview` 空态（未选图） | `app/src/main/res/drawable-nodpi/mascot_glasses_bust.png` | 480×480 透明底胸像，固定 **120dp**（`IdleMascotSize`）居中 |

原图：`冰灵（男）形象/戴智能眼镜.jpg`（2048×2048，纯白底）。

## 2. 尺寸：固定 dp，不要用容器百分比

**空态装饰图的尺寸是设计 token，不是布局的函数。**用「占容器高度的百分比」会把装饰
和视口高度绑死：手机上是得体的占位图，平板 / 折叠屏外屏上就变成广告牌 —— 而这些
恰恰是空态容器最高的地方。

本项目踩过的实测数据：`fillMaxHeight(0.45f)` 在 1080×2400 机型上，预览框高 1720px，
算出 **774px = 258dp**，约为当前主流做法的两倍。

| 尺寸 | 观感 |
| --- | --- |
| 96dp | 偏小，适合列表内的小空态 |
| **120dp** | 采用值。Google 自家 Material 3 空态插画普遍在 120~160dp 区间 |
| 144dp / 168dp | 想要更强品牌存在感时用；168dp 起就开始压过下方操作区 |

另一条约束：空态图应**小于**它下面的主操作控件，让视觉层级是「操作 > 装饰」。
本项目底部 `选图 / 拍照` 两个 FAB 高度就接近 160dp，所以 120dp 是稳妥的。

## 3. 为什么是胸像

预览框去掉顶栏 / 状态条 / 底部按钮后接近正方形，而全身剪影的内容包围盒是
688×1953（宽高比 0.35），只能靠高度撑框，横向留白极大、脸部只剩几十像素，
「智能眼镜」这个与产品主题（锐目 / 识别）最相关的细节看不清。胸像是正方形，
在任何尺寸下都保持构图平衡。全身图一条命令即可重新生成（`<prefix>_full.png`），
生成后若不使用请从仓库删除，别给 APK 留死重。

## 4. 抠图引擎：必须用模型，颜色阈值法在这张图上不成立

深色 surface（`#11212C`）要求真透明底。**三种颜色启发式都试过，都会翻车**，
而且错误只在合成到深色上时才看得见：

| 做法 | 结果 |
| --- | --- |
| 边框泛洪 + `｜rgb − 白｜ ≤ tol` | tol=30 时顺右镜片下方那条近白反光带漏进镜片，再被反解混色按 `1/alpha` 放大成**脸上一个黑洞**；tol 降到 12 躲开了镜片，但躲不开下一条 |
| 改用色度（通道极差）判背景 | 背景色度 p90=2、前襟 p50=47、镜片反光 32，**镜片和大部分前襟都对了**；但衣领上沿有一道近白高光，它是条低色度通道，泛洪顺它咬进领子，切出锯齿边 |
| 形态学闭运算架桥补那道高光缝 | bridge=20 时把**两腿之间的真空隙填成了实心白** —— 闭运算分不清「该补的衣领缝」和「该留空的腿缝」 |

对照事实：已上线的 launcher icon 用同一套泛洪去底却是干净的 —— 老素材
（`冰灵（男）.png`）衬衫蓝度高、整圈有深色描边，而且它最终又合成回近白 `#FDFDFD`，
残留误差根本看不见。放到深色画布上就没这个运气。

**最终方案**：`rembg` 的 `isnet-general-use` 显著性网络出 matte —— 按结构而非色距
判断轮廓，衣领高光、半透明镜片、白衬衫前襟全部完整保留。

```powershell
pip install rembg onnxruntime      # 首次运行下载 ~179MB 模型到 %USERPROFILE%\.rembg
python tools/generate_mascot_asset.py "冰灵（男）形象/戴智能眼镜.jpg" --prefix mascot_glasses --max-dim 480
```

`--max-dim` 按**最大渲染密度**取：120dp × xxxhdpi(4x) = 480px，再大就是纯浪费
（720px 时 509KB → 480px 时 249KB）。

`--engine chroma` 保留着上面那套无依赖回退，**只用于换到"主体与背景色度差异大"的
新素材时应急**；这张戴眼镜原图必须走 `isnet`（默认 `auto` 优先 isnet，rembg 不可用时
才降级并打印提示）。

## 5. matte 后处理（脚本内，顺序有意义）

1. **背景色**：取四边 8px 环的中位数，不写死。
2. **补洞**：`binary_fill_holes` 把完全被包围的低 alpha 区域强制成不透明 —— 眼神光、
   帽徽、衬衫高光永远不该是洞。
3. **去阶梯**：网络内部按 1024 推理，放大回 2048 后边缘有台阶；对 alpha 做
   `--smooth`（默认 1.4px）高斯模糊再轻微拉对比抹平。
4. **反解混色**：只对 `0 < a < 1` 的边缘带做 `subject = (observed − (1−a)·bg) / a`，
   消掉 JPEG 白边。内部像素颜色原样保留 —— 这条约束是踩过坑加的：早先对全图做反解，
   一旦 mask 漏进内部，小 alpha 除法就把正常像素炸成黑块。
5. **裁切 + 缩放**：按 alpha 包围盒紧裁，LANCZOS 缩到 `--max-dim`。

## 6. 换素材 / 调构图

| 想要的效果 | 改什么 |
| --- | --- |
| 人物更大 / 更小 | `ImagePreview.kt` 的 `IdleMascotSize`（120.dp），**同步调整 `--max-dim` = dp × 4** |
| 胸像多露一点身体 | `--bust-fraction`（默认 0.42，调大即多带身体） |
| 边缘有台阶 / 毛刺 | `--smooth`（默认 1.4，调大更柔但可能吃掉细发丝） |
| 边缘残留白晕 | `--smooth` 调大，或检查 `--model` 出的 matte 本身 |
| 想换抠像模型 | `--model birefnet-plus` 等（需联网下载；`isnet-general-use` 已验证够用） |

## 7. 验收标准（换素材后必做）

1. 把成品贴到 `#11212C` 上，**放大 2~2.5 倍**逐处检查：右镜片、衣领上沿高光、白衬衫
   前襟、两腿之间。前三个必须完整，最后一个必须是透的。只看白底预览图发现不了任何问题。
2. 按 120dp 的实际渲染尺寸再看一遍整体比例：装饰应明显小于底部操作按钮。

改完只需 `assembleDebug`，资源类改动与 `modelProfile` 无关。
