# 用户更新日志

## v0.5.1 — 2026-09-17

**修掉眼镜拍照偶尔「一直转圈」的情况。** 以前如果眼镜那边把传图通道悄悄断掉(比如刚升完固件、或长时间待机后),App 还是会照常发拍照命令,然后一直等图片,直到超时才报一句笼统的错误;现在每次拍照前会先确认通道真的就绪,不就绪就直接告诉你「请断开重连后再试」,不会再白等一次。

### 修复

- **修复眼镜拍照偶发长时间无响应**(commit 128a80f):拍照前自检 MTU 与 FA12 传图订阅,发现通道未就绪立即给出明确提示,不再干等整个停包预算;通道健康时这次自检只是一次内存读取,不增加耗时

## v0.5.0 — 2026-09-17

**眼镜现在可以升级固件了,而且识别结果会直接念给你听。** 之前眼镜端固件要更新必须寄回厂家或连电脑刷;现在眼镜开机 App 会自动查更新,有新版就把下载地址通过蓝牙推给眼镜,免去返厂麻烦。识别结果也不再需要盯着屏幕看,眼镜端 TTS 会按违规/警告/信息自动分桶朗读,边戴边听。

### 新增

- **新增眼镜固件 OTA 升级能力**(commit 7901740):眼镜启动后通过游客登录查更新,后端回包里带版本号和下载地址;App 用 0x43 帧把下载地址下发给眼镜,眼镜下载完成后做版本核对并主动重启刷写 —— 不需要返厂,V2.4.5 固件的几个 bug 可以走这条链路快速验证修复
- **新增眼镜物理拍照键一键拍**(commit 7151fb0):眼镜侧 0x11 TLV 携带按键状态通知 App,按下拍照键 App 自动起一次拍照流程;忙时(正在拍照 / 正在传图)会排队重试,松手再按也能补上,不再需要掏出手机点「拍照」按钮
- **新增识别结果眼镜端自动播报**(commit f572dd4):TTS 按严重度分桶朗读违规 / 警告 / 信息,开头先报命中总数,每条命中念依据法规;命中数为 0 也会播一句「AI 识别无违规」兜底而不是默默不响;只念非零分类,避免念一堆「无违规」的零桶刷屏

### 修复

- **修复固件 OTA 后读版本必超时、只能重启 App 才能恢复的问题**(commit df8c6ba):链路存活校验 + `resetLink` 在断连 / 超时场景主动复位链路状态,不再卡死

## v0.4.4 — 2026-09-16

**眼镜拍照传图变快了,而且不会再卡在「补洞」阶段报错了。** 之前 V2.4.5 固件在突发传输时会漏掉一部分块(实测一轮只到 13-25%),补洞又按「一次一请 + 等 2.5 秒」的节奏走,导致一张 48-57 KB 的照片要 60 秒才能补完,且最后给的报错「眼镜未响应补发请求」与实际不符 —— 眼镜其实每一轮都答了;现在改成一轮批量请求 + 短等待 + 按实际进展判死,同样大小的照片 19-22 秒就能收齐,App 也把「App 在做事」明确显示给用户。

### 修复

- **修复了眼镜拍照传图慢、最后报「眼镜未响应补发请求」的问题**:根因不在 App 漏块(收图端块数与系统通知次数字节级一致),而是补洞循环节奏和固件实际行为不匹配 —— 眼镜 V2.4.5 每次只回 1~3 个块,而之前沿用「一轮一个 op2 + 等 2.5 秒」节奏实测只有 ~0.3 块/秒;改成「一轮批量 20 个 op2、480 字节步进、250 毫秒等待、连续 10 秒无进展判死」的策略后,补洞吞吐提到 ~16-20 块/秒,48-57 KB 照片 19-22 秒收齐
- **修复了补洞过程中进度文案让用户以为 App 卡死的问题**:之前全程都显示「拍照中…」(即使已经在批量补洞),现在新增补洞阶段文案「补传缺块中…(眼镜漏发,正在逐块补回)」,且取消/失败文案改为「传图未完成(缺 N/M 字节)」如实告知缺了多少字节

## v0.4.3 — 2026-09-16

**两个修好了的问题**:一个是首页点「眼镜」按钮 App 直接闪退的问题;另一个是下载更新过程中点「重试」或「取消」按钮没反应的问题。两个都不会再出现了。

### 修复

- **修复了首页点「眼镜」按钮 App 闪退的问题**:之前全新安装后(或者清过 App 数据后)首次点「眼镜」按钮,App 会直接关掉,什么都不提示;现在改成先弹系统权限申请,允许后会正常显示提示去系统蓝牙配对眼镜的对话框;如果之前拒过一次,会显示「继续授权」;如果勾了「不再提示」永久拒绝,会显示「去应用设置」按钮,不再闪退
- **修复了下载更新失败后「重试」按钮点不响应的问题**:之前下载更新如果因为网络或者别的什么原因失败了,显示「下载失败,请重试」但点重试按钮没反应,必须关掉 App 重开才能看到更新;现在重试按钮一定会触发重试,不再有这个卡死的现象
- **修复了取消下载后「重试」按钮消失的问题**:之前点取消下载后会显示「已取消」状态,但没有重试按钮,想重新下载只能关掉 App 重开;现在「已取消」状态下也会显示「重试」按钮,直接点就能继续下载
