# 冰灵锐目 激活码签发工具 — 安装与使用

> 给首次使用的市局广告处同事看的文档。按以下顺序操作即可。
>
> **本工具与本 App 仅供市局 / 区县局单位系统内部使用,不属于商业软件。** 文档里提到的"用户"指单位系统内的其他同事(区/县局广告口),不是商业客户。

## 一、准备工作(一次性)

### 1.1 电脑要求

- Windows 10 或 Windows 11
- **不需要安装 Python** —— 所有逻辑已经打包在 `.exe` 里
- **不需要联网** —— 整个签码过程不连任何外网
- **不需要单独获取 PEM 私钥** —— 私钥已由开发者内嵌于 `.exe`,启动时自动加载

### 1.2 放置工具目录

把开发者发来的整个文件夹放到一个你能找到的位置,例如:

```
D:\icevision-license-tool\
├── 签发工具.exe
└── 许可证台账.csv   (台账模板,首次签发后自动写入记录)
```

**整个文件夹要保留**:`签发工具.exe` 是签发工具(内嵌私钥);`许可证台账.csv` 是签发历史(每次签发 / 续期自动追加一行)。换电脑 / 换 Windows 用户时,把这个文件夹整体拷过去即可,无需任何额外操作。

## 二、启动签发工具

### 2.1 双击 `签发工具.exe`

- **不弹黑窗口**(Win10/11 的 Defender SmartScreen 可能弹"未知应用"警告 → 点"更多信息" → "仍要运行")
- 主窗口弹出,标题"冰灵锐目 激活码签发工具"
- 窗口顶部应显示 `[内嵌] <私钥路径>`,表示私钥已自动加载 —— 看到这一行,直接进入 §三 签发即可
- 主窗口底部有一条**红色安全提示**,提醒本工具的私钥已内嵌于 .exe 物理文件,请严格控制 .exe 的分发对象

### 2.2 (一般不需要) 手动切换私钥

窗口顶部「选择私钥 PEM 文件」按钮 —— 99% 的场景**不需要点**(开发者发的 `.exe` 已经内嵌了正确的私钥)。仅在以下两种场景才用:

- 开发者发来更新版私钥替换 .exe 内嵌的旧私钥
- 测试场景(临时换成自己的私钥)

## 三、签发一张码

主窗口中间的表单:

| 字段 | 填写规则 | 示例 |
|---|---|---|
| **名称** | 单位用户名(区/县局广告口的同事名)。签发 / 续期都靠它定位台账 | `张某执法一中队` |
| **管理处室** | 当前下拉只含「广告处」一个选项。新增部门需要开发者改代码发新 `.exe` | `广告处` |
| **到期日** | 7 选 1 下拉: 1 个月 / 3 个月 / 半年 / 1 年 / 2 年 / 5 年 / 永久 | (默认 1 年) |

点击「签发新码」或「续期」,按钮按表单当下选中的预设自动换算成 yyyymmdd。

点击 **「签发新码」**,底部结果区出现:

```
[✓ OK]
ICS1.eyJ2IjoxLCJuIjoi5byg5rWq5a6J5Lit56uZIiwiZSI6MjAyNzEwMTQsImQiOiJhZCJ9.MEU...
```

整段复制下来通过 U 盘 / 邮件附件 / 蓝牙发给对方(详见第九节)。

**名称不能复用**:已签发的名称必须用「续期」,不能再次「签发新码」。

## 四、管理处室(部门归属)

工具表单里有一个**「管理处室」下拉框**。当前只有一个选项:「广告处」(对应 key `ad`)。

- 签发 / 续期时,**管理处室一定要选对**。签出的码里会带一个 `d` 字段记录是哪个处室签的。
- **跨处室续期被禁止**:如果 `某单位` 当初是「广告处」签的,「食品口」(未来新增的部门)不能续期 — 工具会拒绝并提示「由 ad 签发,不能由 food 续期」。要让食品口接管,需要先用「食品口」走一次签发新码流程。
- App 端**不强制 d** 值:激活码进 App 后,App 只校验 `d` 字段存在 + 长度 ≤ 8。d 是给签发工具自己用的台账分类,不参与 App 验证。

新增管理处室需要开发者改代码发新 `.exe`,工具本身不接受外部配置。

## 五、续期一张码

按 **名称** 续期:

1. 名称字段填**完整单位名**(例如 `张某执法一中队`,与签发时一字不差)
2. 管理处室下拉选**当初签发的那个处室**(通常就是「广告处」)
3. 到期日选新的预设(必须**晚于**当前到期日,否则工具拒绝)
4. 点 **「续期」**

工具会自动校验:

- name 是否存在(否则报"name 不存在,请用 new")
- 管理处室 d 是否与台账里同名记录的 d 一致(否则报"跨处室续期被禁止")
- 新到期日是否晚于当前(否则报"已续到更晚,拒绝缩短")
- 当前已是永久(则报"已是永久,无需续期")

## 六、完整验签

「完整验签」按钮 → 粘贴 ICS1 → 显示 OK / FAIL。

- **OK**:签名有效 + 未过期
- **FAIL**:签名错 / 已过期 / 用户名不匹配

**验签功能不修改台账**:可以放心给来电咨询的同事验证对方拿到的码是不是你签的。

## 七、台账

每次签发 / 续期,工具会在**当前目录**(`签发工具.exe` 同目录)写下 / 追加 `许可证台账.csv`(Excel 可打开),记录:

```
签发时间,操作,名称,到期日,备注,签发处室
2026-10-12T10:30,new,张某执法一中队,20271014,,ad
2026-10-12T11:00,renew,张某执法一中队,20271014,对方来电续期,ad
```

要查某单位的到期日,看 `名称` 列(续期按 name 定位)。`签发处室` 是管理处室 key(`ad` = 广告处)。

台账**不要删除、不要改名、不要放到别的目录**。它是签发历史的唯一记录,也是 §五 续期校验的唯一数据源。

## 九、常见问题

**Q: 我换了电脑,新电脑怎么用?**
A: 把 `签发工具.exe` + `许可证台账.csv` 整个目录拷到新电脑,双击 `.exe` 即可。私钥已内嵌于 .exe,无需任何额外操作。**台账也要拷过去**,否则查不到历史签发记录、也无法续期老用户。

**Q: 我换了 Windows 用户(从 admin 换成 User),原来签的码还能验吗?**
A: 可以。`.exe` 是单文件可执行,跟 Windows 用户无关。带 `.exe` + 台账去新用户下运行即可。

**Q: 对方说激活码无效,但我签的时候看着对?**
A: 让对方把激活码原文**完整复制**过来(包括 `ICS1.` 前缀),不要用微信截图。用「完整验签」按钮验证,显示 OK 才能发。ICS1 约 130 字符,长按复制后字符变短通常是微信 IM 截断了,不是码本身的问题。

**Q: .exe 丢了 / 落到外部人手里了怎么办?(失私钥控制权)**
A: 灾难性事故 —— `.exe` 是私钥 + 工具合一的副本,**失 `.exe` = 失私钥**。任何拿到 `.exe` 副本的人都能反编译提取私钥、用同一私钥签发 / 续期任意码。处置:
1. 立刻联系开发者,告知失 `.exe` 控制权
2. 开发者会重新生成 ECDSA P-256 密钥对 + 重新打 `.exe`
3. App 公钥也要换 → 开发者需发新版本(否则 App 不认新码)
4. 已激活客户拿到的旧码全部失效,需要重新签发新版码

失 `.exe` 控制权之后,旧的 `.exe` 副本仍然能签发有效签名(只要对方拿到的是同一个 `.exe`),所以**关键不是封堵旧副本,而是尽快让 App 端的公钥失效** —— 这必须靠开发者发版。

**Q: 一张码能在多台设备用吗?**
A: 可以。同一张 ICS1 码,在任何设备上登录 App 都能进。但同一台设备**任何时刻只一个活动账号**(后登录覆盖先登录的 DataStore)。

**Q: 对方拿到码后第一次登录要联网吗?**
A: 不要。App 全程离线验证。**手机没信号也能登录。**

## 十、把激活码发给对方 —— 传输渠道选择

**签出的 ICS1 字符串(130 字符左右)有特殊字符和大小写敏感**,必须用**保留 base64 完整性**的渠道传给区/县局用户:

| 渠道 | 可用 | 原因 |
|---|---|---|
| U 盘当面交 | ✅ | 文件传输,无编码变换 |
| 邮件附件(ICS1.txt) | ✅ | 附件原样传输 |
| 蓝牙 AirDrop / Nearby Share | ✅ | 二进制传输 |
| **微信 IM 文本消息** | ❌ | 微信 IM 会改 base64 字符(典型表现:对方长按复制后只剩 50~80 字符,丢尾部,verify 报 "激活码格式错误") |
| **手机 SMS 短信** | ❌ | 短信长度限制 + GSM 编码变换 |
| **记事本 / Word 转 PDF** | ✅ if 文件转交 | 文件传输 |

**实操流程**:

1. 你签出 ICS1(点「复制 ICS1 字符串」按钮自动复制到剪贴板)
2. 粘到一个 `.txt` 文件,改名为 `道里区-20271014.txt`
3. 通过 U 盘 / 邮件附件 / 蓝牙发给对方
4. 对方收到后,长按文件名 → 用文本编辑器打开 → 全选复制 → 粘到 App「激活码」输入框
5. App 顶部短粘贴(单行显示)只显示前 ~80 字符,但内部状态是完整 ICS1,直接点登录即可

**不要做的事**:

- 把 ICS1 直接粘到微信 IM 发给对方
- 把 ICS1 转图片发(OCR 会丢字符)
- 抄写到纸上拍照传
