# 冰灵锐目 激活码签发工具 — 安装与使用

> 给首次使用的市局广告处同事看的文档。按以下顺序操作即可。

## 一、准备工作(一次性)

### 1.1 电脑要求

- Windows 10 或 Windows 11
- **不需要安装 Python**——所有逻辑已经打包在 `.exe` 里
- **不需要联网**——整个签码过程不连任何外网

### 1.2 把 PEM 文件存到你能记住的位置

PEM 是 ECDSA P-256 私钥文件,你只需要单独取一次(当面/U 盘/微信),存到本地,例如:

```
D:\icevision-license-密钥\icespiritai-license-private.pem
```

**重要**:这个文件丢失 = 所有已激活客户都得重新发版,务必:
- **至少做 2 份离线备份**(密码保险柜 / 加密 U 盘)
- 不要发邮件、网盘、云盘等任何会同步到外网的工具
- 删除原始传输(微信发完文件后撤回)

## 二、启动签发工具

### 2.1 双击 `签发工具.exe`

第一次运行时:
- **不弹黑窗口**(Win10/11 的 Defender SmartScreen 可能弹"未知应用"警告 → 点"更多信息" → "仍要运行")
- 主窗口弹出,标题"冰灵锐目 激活码签发工具"

### 2.2 导入 PEM 私钥

主窗口顶部:**选择私钥 PEM 文件** 按钮。

操作:
1. 点击按钮
2. 在弹出的文件选择对话框里,选刚才保存的 `icespiritai-license-private.pem`
3. 顶部显示 `D:\...\icespiritai-license-private.pem` 表示导入成功

私钥会被 Windows 的 DPAPI 机制加密,存到:
```
C:\Users\<你的用户名>\AppData\Roaming\IceSpiritAI\license_key.dpapi
```

**这台电脑 + 这个用户**之后启动 .exe 不再需要选 PEM(自动读取)。换电脑或换用户要重新选。

## 三、签发一张码

主窗口中间的表单:

| 字段 | 填写规则 | 示例 |
|---|---|---|
| **UID** | 6 位,字母数字。**系统视角的客户 ID**,客户不可见。**仅签发新码时填写,续期按名称走** | `acme01` |
| **名称** | 客户名(用户给 App 输入的名字)。签发 / 续期都靠它定位台账 | `张某执法一中队` |
| **管理处室** | 当前下拉只含「广告处」一个选项。新增部门需要开发者改代码发新 `.exe` | `广告处` |
| **到期日** | `yyyyMMdd` 格式,**或留空 / 写 0 = 永久** | `20270630` |

点击 **「签发新码」**,底部结果区出现:

```
[✓ OK]
ICS1.eyJ2IjoxLCJ1IjoiYWNtZTAxIiwibiI6IuW3peS6kuiBlOe9kSIsImUiOjIwMjcwNjMwfQ.MEU...
```

整段复制下来发给客户(微信 / 邮件 / U 盘)。

**uid 不能复用**:已签发的 uid 必须用「续期」,不能再次「签发新码」。

## 三、管理处室(部门归属)

工具表单里有一个**「管理处室」下拉框**。当前只有一个选项:「广告处」(对应 key `ad`)。

- 签发 / 续期时,**管理处室一定要选对**。签出的码里会带一个 `d` 字段记录是哪个处室签的。
- **跨处室续期被禁止**:如果 `某客户` 当初是「广告处」签的,「食品口」(未来新增的部门)不能续期 — 工具会拒绝并提示「由 ad 签发,不能由 food 续期」。要让食品口接管,需要先用「食品口」走一次签发新码流程。
- App 端**不强制 d** 值:激活码进 App 后,App 只校验 `d` 字段存在 + 长度 ≤ 16。d 是给签发工具自己用的台账分类,不参与 App 验证。

新增管理处室需要开发者改代码发新 `.exe`,工具本身不接受外部配置。

## 四、续期一张码

按 **名称** 续期(不再需要记住 6 位 uid):

1. 名称字段填**完整客户名**(例如 `张某执法一中队`,与签发时一字不差)
2. 管理处室下拉选**当初签发的那个处室**(通常就是「广告处」)
3. 到期日写新日期(必须**晚于**当前到期日,否则工具拒绝)
4. 点 **「续期」**

工具会自动校验:
- name 是否存在(否则报"name 不存在,请用 new")
- 管理处室 d 是否与台账里同名记录的 d 一致(否则报"跨处室续期被禁止")
- 新到期日是否晚于当前(否则报"已续到更晚,拒绝缩短")
- 当前已是永久(则报"已是永久,无需续期")

## 五、完整验签(需要私钥)

「完整验签」按钮 → 粘贴 ICS1 → 显示 OK / FAIL。

- **OK**:签名有效 + 未过期
- **FAIL**:签名错 / 已过期 / 用户名不匹配

## 六、台账

每次签发 / 续期,工具会在**当前目录**写下 `许可证台账.csv`(Excel 可打开),记录:

```
ts,op,uid,name,issued_expire,note,d
2026-10-12T10:30,new,acme01,某客户,20270630,,ad
2026-10-12T11:00,renew,acme01,某客户,20271231,客户来电续期,ad
```

要查某客户的到期日,看 `name` 列(续期按 name 定位)。`uid` 是 6 位内部代码(签发新码时分配,客户不需要知道)。`d` 是管理处室 key(`ad` = 广告处)。

## 七、常见问题

**Q: 我换了电脑,新电脑怎么用?**
A: 把 PEM 文件拷到新电脑,启动 .exe 后"选择私钥 PEM 文件"重新选一次。DPAPI 不跨电脑。

**Q: 我换了 Windows 用户(从 admin 换成 User),A: 在新用户下首次启动 .exe 时重新选 PEM。DPAPI 绑用户,不是绑机器。

**Q: 客户说激活码无效,但我签的时候看着对?**
A: 让客户把激活码原文**完整复制**过来(包括 `ICS1.` 前缀),不要用微信截图。用「完整验签」按钮验证,显示 OK 才能发。

**Q: 私钥丢了怎么办?**
A: 灾难性事故。所有已激活客户都需重新发版。立刻:
1. 在另一台电脑上跑 `openssl ecparam -name prime256v1 -genkey -noout -out new-private.pem`
2. 用新私钥签发新码发给所有客户
3. 通知开发者更新 App 的 BuildConfig 公钥 + 发版

这就是为什么私钥**一定要做离线备份**。

**Q: 一张码能在多台设备用吗?**
A: 可以。同一张 ICS1 码,在任何设备上登录 App 都能进。但同一台设备**任何时刻只一个活动账号**(后登录覆盖先登录的 DataStore)。

**Q: 客户拿到码后第一次登录要联网吗?**
A: 不要。App 全程离线验证。**手机没信号也能登录。**
